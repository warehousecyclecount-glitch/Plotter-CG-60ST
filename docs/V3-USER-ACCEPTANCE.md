# Production User Acceptance — Mimaki CG-60ST

ใช้ checklist นี้สำหรับทดสอบ **Production จริงบนเครื่องบริษัท** หลัง V4 ถูก Promote เข้า `main` แล้ว

Automated tests ตรวจ Browser / Model / Export structure ได้ แต่หัวข้อนี้ต้องยืนยันกับ CorelDRAW, FineCut และ CG-60ST จริงเท่านั้น

## 1. Editor / V4 Canvas

- เปิด Production แล้วสร้าง **ข้อความอย่างเดียว** ได้
- สร้าง **กรอบอย่างเดียว** ได้
- สร้างกรอบก่อน แล้วกด **ใส่ข้อความในกรอบ** ได้
- เมื่อคลิก **ขอบกรอบ** ที่มีข้อความอยู่ด้านใน ต้องเลือกกรอบ/ทั้งชุดได้ ไม่ถูก Floating Toolbar บัง
- ลากกรอบที่มีข้อความแล้วทั้งชุดตามกัน
- ลากข้อความภายในกรอบแล้วกรอบไม่ขยับ
- Resize 8 จุดทำงานถูกทิศ
- Rotate / Quantity ทำงานตามที่เห็นบนจอ
- Multi-select / Marquee select ใช้งานได้
- Lock แล้วลาก/Resize ชิ้นนั้นไม่ได้
- Right-click menu ใช้งานได้
- Zoom / Pan / Ruler / Guide ไม่ทำให้ตำแหน่งจริงของชิ้นงานเปลี่ยน
- Snap, X/Y/W/H/Rotation และ Arrow keys ใช้งานได้

## 2. Save / Open / Autosave

- แก้งานแล้วรอให้สถานะ Autosave บันทึกสำเร็จ
- Reload หน้าเว็บแล้วระบบต้องแจ้งว่ามีงานล่าสุดให้กู้คืน โดย **ไม่ควรเขียนทับ Project ปัจจุบันเองแบบเงียบ ๆ**
- กด `ไฟล์ → กู้คืนงานล่าสุด` แล้วงานกลับมาถูกต้อง
- กด **ดาวน์โหลดไฟล์งาน** ได้ไฟล์ `.cg60st.json`
- เปิดไฟล์นั้นกลับมาแล้วขนาด/ตำแหน่ง/จำนวน/การหมุนเหมือนเดิม
- ลอง `StickerLayout-V3-Standalone.html` จากไฟล์เดียวบนเครื่องบริษัท

## 3. CorelDRAW Scale Gate

- ใน `ตรวจงาน` หรือเมนู `ส่งออก` กด **ไฟล์ทดสอบ 100 mm**
- เปิด `CG60ST-Calibration-100mm.svg` ใน CorelDRAW
- สี่เหลี่ยมต้องวัดได้ **100 × 100 mm**
- ถ้าไม่ใช่ 100 × 100 mm ให้หยุดก่อนส่งงานจริง
- จดค่าที่ CorelDRAW import มา เช่น 99.8 × 99.8 หรือ 100.2 × 100.2 mm เพื่อใช้หาสาเหตุจากหลักฐานจริง

## 4. Corel Editable Gate

- Export **แก้ต่อใน Corel**
- เปิดใน CorelDRAW เวอร์ชันที่บริษัทใช้งานจริง
- ตรวจว่าขนาดกระดาษและตำแหน่งไม่เปลี่ยน
- ทดลองใช้ Text tool แก้ข้อความ
- ตรวจหลายบรรทัด / ตัวหนา / การหมุน
- ตรวจว่าฟอนต์ตรงกับเว็บ หรือ Corel แจ้ง missing/substituted font หรือไม่
- ถ้าฟอนต์ถูกแทน ให้ตรวจว่าความกว้าง/สูงของข้อความเปลี่ยนหรือไม่

## 5. Cut Ready / FineCut Gate

- Export **ไฟล์พร้อมตัด**
- ยืนยันว่า Browser อ่านฟอนต์ในเครื่องได้ หรือเลือกไฟล์ฟอนต์ fallback ได้ตามปกติ
- เปิดไฟล์ใน CorelDRAW แล้วตรวจว่า Text ถูกส่งเป็น Curve/Path ตามที่ตั้งใจ
- เปิด FineCut แล้วตรวจ Preview และขนาดงานอีกครั้ง
- ตรวจว่า Frame และตัวอักษรเป็นเส้นตัดครบ ไม่มีชิ้นหายหรือเส้นเกิน
- ทดสอบงานชิ้นเล็กก่อนส่งงานใหญ่

## 6. CG-60ST Physical Cut Gate

- ตัดชิ้นทดสอบที่รู้ขนาดแน่นอน
- วัดขนาดจริงหลังตัดเทียบกับไฟล์
- ตรวจตัวอักษรเล็ก, มุมกรอบ, เส้นตรงยาว และงานหมุน 90° อย่างน้อยอย่างละหนึ่งตัวอย่าง
- ตรวจว่า Frame/เส้นช่วยแกะและตัวอักษรถูกตัดครบ
- ถ้าขนาดจริงคลาด ให้แยกว่าเกิดจาก SVG/Corel/FineCut หรือค่าชดเชยของเครื่อง ก่อนแก้ซอฟต์แวร์เว็บ

## วิธีรายงานผลกลับมา

ถ้าพบจุดผิด ให้ส่งเฉพาะหลักฐานที่เห็นจริง เช่น:

- ทำอะไร
- คาดหวังอะไร
- เกิดอะไรจริง
- ขนาดที่เว็บแสดง
- ขนาดที่ CorelDRAW แสดง
- ขนาดที่ FineCut แสดง
- ขนาดชิ้นจริงหลังตัด
- Screenshot ถ้ามี

Production ถูก Deploy แล้ว ดังนั้น checklist นี้ใช้เป็น **Real-device acceptance gate** เพื่อยืนยัน workflow จริง ไม่ใช่เงื่อนไขก่อน Merge V4 อีกต่อไป
