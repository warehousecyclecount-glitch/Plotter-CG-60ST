# V3 User Acceptance — Mimaki CG-60ST

ใช้ checklist นี้ตอนที่พร้อมทดสอบบนเครื่องบริษัท ไม่ต้องทดสอบระหว่างพัฒนา

## 1. Editor

- เปิด V3 แล้วสร้าง **ข้อความอย่างเดียว** ได้
- สร้าง **กรอบอย่างเดียว** ได้
- สร้างกรอบก่อน แล้วกด **ใส่ข้อความในกรอบ** ได้
- ลากกรอบที่มีข้อความแล้วทั้งชุดตามกัน
- ลากข้อความภายในกรอบแล้วกรอบไม่ขยับ
- Resize / Rotate / Quantity ทำงานตามที่เห็นบนจอ
- Snap, X/Y/W/H/Rotation และ Arrow keys ใช้งานได้

## 2. Save / Open

- แก้งานแล้ว Reload หน้าเว็บ งานล่าสุดกลับมาเองจาก Autosave
- กด **บันทึกงาน** ได้ไฟล์ `.cg60st.json`
- เปิดไฟล์นั้นกลับมาแล้วขนาด/ตำแหน่ง/จำนวนเหมือนเดิม
- ลอง `StickerLayout-V3-Standalone.html` จากไฟล์เดียวบนเครื่องบริษัท

## 3. CorelDRAW Scale Gate

- ใน Preflight กด **ไฟล์ทดสอบ 100 mm**
- เปิด `CG60ST-Calibration-100mm.svg` ใน CorelDRAW
- สี่เหลี่ยมต้องวัดได้ **100 × 100 mm**
- ถ้าไม่ใช่ 100 × 100 mm ให้หยุดก่อนส่งงานจริงและบันทึกค่าที่ Corel import มา

## 4. Corel Editable Gate

- Export **ส่งไปแก้ต่อใน Corel**
- เปิดใน CorelDRAW
- ตรวจว่าขนาดกระดาษและตำแหน่งไม่เปลี่ยน
- ทดลองใช้ Text tool แก้ข้อความ
- ตรวจว่าฟอนต์ตรงกับเว็บ หรือ Corel แจ้ง missing/substituted font หรือไม่

## 5. FineCut / CG-60ST Gate

- ก่อนตัดจริง Convert to Curves ใน Corel ถ้า workflow บริษัทต้องการ
- เปิด FineCut และตรวจ preview/ขนาดงานอีกครั้ง
- ทดสอบชิ้นเล็กก่อน
- วัดขนาดชิ้นจริงเทียบกับไฟล์
- ตรวจ Frame/เส้นช่วยแกะและตัวอักษรว่าตัดครบ

เมื่อ 5 หมวดนี้ผ่าน จึงอนุมัติ Promote V3 เข้า `main` และสร้าง Standalone ตัว production
